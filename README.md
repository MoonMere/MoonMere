## Personal projects made with AI

I build these with Claude Code, and the AI writes all of the code. I've found the hard part is working out exactly what to build and guiding the AI through it. My part is deciding what each project should be and who it is for, choosing what comes first, setting the rules the AI agents work by, and checking the results myself.

### [Kara and Todd's House from *Detroit: Become Human*](https://github.com/MoonMere/detroit-become-human-kara-todd-house)

An unofficial fan recreation of the house from the game. It contains no assets from the game and is not affiliated with Sony Interactive Entertainment or Quantic Dream. It runs in a web browser, has no commercial purpose and is still a work in progress.

I set the overall direction and review the results against the original game.

### [外婆爱游戏 (Granny Loves Games)](https://github.com/MoonMere/lianliankan-wechat-game)

A lianliankan (连连看) tile matching game, released on WeChat as a Mini Game. Lianliankan games on Chinese platforms are packed with ads, so I made one with none.
