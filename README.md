## Current project

**[LiveNerf across Claude Code versions](https://github.com/MoonMere/livenerf-across-versions)**<br>
Same model, same 78 questions, 39 versions of Claude Code. The experiment asks whether the Claude Code version changes how well Claude Opus 5.5 answers, or how much it thinks. The rule for reading the results was registered before the run, and the results will be published whatever they show.<br>
<sub>November 2026 · made with Claude Code, mainly with Claude Fable 5.2</sub>
